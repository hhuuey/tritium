# 1. 最重要的思想

**不要直接求矩阵对矩阵的导数。**

例如

\[
\frac{\partial \Sigma}{\partial M}
\]

严格来说这是一个四阶 Tensor（Jacobian）。

实际推导（包括 PyTorch、JAX、SLAM、3DGS）几乎都不会这么做。

而是采用：

> **Forward：写微分（Differential）**
>
> **Backward：写梯度传播（Gradient Propagation）**

---

# 2. Matrix Differential（矩阵微分）

## 一元函数

\[
L=f(x)
\]

有

\[
dL=\frac{dL}{dx}dx.
\]

---

## 向量函数

设

\[
x\in\mathbb R^n
\]

则

\[
dL
=
\nabla_xL^Tdx.
\]

即

\[
dL
=
\sum_i
\frac{\partial L}{\partial x_i}
dx_i.
\]

---

## 矩阵函数

设

\[
X\in\mathbb R^{m\times n}
\]

矩阵梯度定义为

\[
\boxed{
dL
=
\operatorname{tr}
\left(
\left(
\frac{\partial L}{\partial X}
\right)^TdX
\right)
}
\]

这是整个矩阵微积分最重要的公式。

---

# 3. 为什么会出现 trace？

矩阵没有向量那样的点积。

矩阵采用的是

## Frobenius Inner Product

定义

\[
\boxed{
A:B
=
\sum_{ij}
A_{ij}B_{ij}
}
\]

它满足

\[
\boxed{
A:B
=
\operatorname{tr}(A^TB)
}
\]

因此

矩阵版

\[
g^Tdx
\]

自然写成

\[
\boxed{
dL
=
\operatorname{tr}(G^TdX)
}
\]

其中

\[
G=\frac{\partial L}{\partial X}.
\]

---

# 4. Matrix Gradient 的定义

实际上

\[
\boxed{
dL
=
\operatorname{tr}
\left(
\left(
\frac{\partial L}{\partial X}
\right)^TdX
\right)
}
\]

并不是推导出来的。

它就是

**Matrix Gradient 的定义。**

Matrix Cookbook、Magnus & Neudecker 都采用这个定义。

---

# 5. Matrix Differential 的基本规则

## 加法

\[
d(A+B)=dA+dB.
\]

---

## 乘法

\[
\boxed{
d(AB)
=
(dA)B
+
A(dB)
}
\]

就是普通乘积法则。

---

## 转置

\[
d(A^T)
=
(dA)^T.
\]

---

## 逆矩阵

\[
\boxed{
d(A^{-1})
=
-A^{-1}(dA)A^{-1}
}
\]

---

## Trace

\[
d(\operatorname{tr}(A))
=
\operatorname{tr}(dA).
\]

---

# 6. Trace Trick（Trace 技巧）

最重要的性质：

## 循环性质

\[
\boxed{
\operatorname{tr}(ABC)
=
\operatorname{tr}(BCA)
=
\operatorname{tr}(CAB)
}
\]

注意：

不能改变顺序。

只能整体循环。

例如

正确：

\[
ABC
\rightarrow
BCA
\]

错误：

\[
ABC
\rightarrow
ACB
\]

---

## 转置

\[
\operatorname{tr}(A)
=
\operatorname{tr}(A^T).
\]

---

## 与 Differential 配合

例如

\[
dL
=
\operatorname{tr}
(G^TAdXB)
\]

利用循环性质

得到

\[
=
\operatorname{tr}
(BG^TAdX)
\]

于是立即得到梯度。

---

# 7. Forward Differential 与 Backward Gradient

现代自动微分采用：

Forward：

\[
dY=\cdots
\]

Backward：

利用

\[
dL
=
\operatorname{tr}
(G^TdY)
\]

推出

\[
\frac{\partial L}{\partial X}.
\]

而不是直接构造 Jacobian。

---

# 8. 常见求导模板

---

## (1)

\[
Y=AXB
\]

### Forward

\[
\boxed{
dY
=
A(dX)B
}
\]

---

### Jacobian（元素形式）

元素展开

\[
Y_{ij}
=
\sum_{a,b}
A_{ia}
X_{ab}
B_{bj}
\]

因此

\[
\boxed{
\frac{\partial Y_{ij}}
{\partial X_{kl}}
=
A_{ik}
B_{lj}
}
\]

---

### Backward

若

\[
G
=
\frac{\partial L}{\partial Y}
\]

则

\[
\boxed{
\frac{\partial L}{\partial X}
=
A^TGB^T
}
\]

---

## (2)

\[
Q
=
AA^T
\]

### Forward

\[
\boxed{
dQ
=
(dA)A^T
+
A(dA)^T
}
\]

---

### 元素导数

展开

\[
Q_{ij}
=
\sum_k
A_{ik}A_{jk}
\]

得到

\[
\boxed{
\frac{\partial Q_{ij}}
{\partial A_{mn}}
=
\delta_{im}A_{jn}
+
\delta_{jm}A_{in}
}
\]

---

### Backward

若

\[
G
=
\frac{\partial L}{\partial Q}
\]

则

\[
\boxed{
\frac{\partial L}{\partial A}
=
(G+G^T)A
}
\]

若

\[
G=G^T
\]

则

\[
\boxed{
\frac{\partial L}{\partial A}
=
2GA
}
\]

---

## (3)

\[
A
=
BLB^T
\]

### Forward

\[
\boxed{
dA
=
B(dL)B^T
}
\]

---

### Jacobian

利用

\[
A_{ij}
=
\sum_{a,b}
B_{ia}
L_{ab}
B_{jb}
\]

得到

\[
\boxed{
\frac{\partial A_{ij}}
{\partial L_{kl}}
=
B_{ik}
B_{jl}
}
\]

---

### Backward

若

\[
G
=
\frac{\partial L_{loss}}
{\partial A}
\]

则

\[
\boxed{
\frac{\partial L_{loss}}
{\partial L}
=
B^TGB
}
\]

---

# 9. 3DGS 协方差推导

论文定义

\[
\Sigma
=
RSS^TR^T.
\]

令

\[
M=RS.
\]

则

\[
\boxed{
\Sigma
=
MM^T.
}
\]

---

Forward

\[
\boxed{
d\Sigma
=
(dM)M^T
+
MdM^T
}
\]

---

Backward

若

\[
G
=
\frac{\partial L}{\partial\Sigma}
\]

则

\[
\boxed{
\frac{\partial L}{\partial M}
=
(G+G^T)M
}
\]

由于

协方差梯度也是对称矩阵

所以

\[
\boxed{
\frac{\partial L}{\partial M}
=
2GM
}
\]

---

# 10. 为什么论文写

\[
\frac{d\Sigma}{dM}
=
2M^T
\]

严格来说

这是不严谨的。

真正的

\[
\frac{\partial\Sigma}{\partial M}
\]

应该是

四阶 Tensor。

论文实际上省略了

\[
\frac{\partial L}{\partial\Sigma}
\]

直接写出了

Backward Rule。

它真正表达的是

```text
grad_M = 2 * grad_Σ * M
```

而不是 Jacobian。

因此

它不是严格意义上的矩阵导数。

---

# 11. 3DGS 中另一条重要公式

论文

\[
\Sigma'
=
U\Sigma U^T
\]

其中

\[
U=JW.
\]

展开

\[
\boxed{
\Sigma'_{ij}
=
\sum_{a,b}
U_{ia}
\Sigma_{ab}
U_{jb}
}
\]

因此

\[
\boxed{
\frac{\partial\Sigma'_{mn}}
{\partial\Sigma_{ij}}
=
U_{mi}
U_{nj}
}
\]

例如

\[
\boxed{
\frac{\partial\Sigma'_{11}}
{\partial\Sigma_{ij}}
=
U_{1i}
U_{1j}
}
\]

正是论文中的推导。

# 12. 推荐遵循的矩阵求导规范（★★★★★）

以后阅读论文时，推荐始终遵循以下流程：

**Step 1：写前向微分**

\[
dY=\cdots
\]

**Step 2：引入损失梯度**

\[
dL
=
\operatorname{tr}
\left(
\left(
\frac{\partial L}{\partial Y}
\right)^TdY
\right)
\]

**Step 3：利用 Trace Trick**

不断循环矩阵

直到

\[
dL
=
\operatorname{tr}
\left(
\left(
\frac{\partial L}{\partial X}
\right)^TdX
\right)
\]

**Step 4：直接读出梯度**

整个过程中：

- 不需要四阶 Jacobian
- 所有梯度与变量维度一致
- 与 PyTorch Autograd 完全一致

---

# 13. 一句话总结

> **Forward 写 Differential，Backward 写 Gradient，所有梯度通过**
>
> \[
> dL=\operatorname{tr}\left(\left(\frac{\partial L}{\partial X}\right)^TdX\right)
> \]
>
> **统一定义，并利用 Trace Trick 完成梯度传播。**

这是现代矩阵微积分、自动微分、SLAM、BA、NeRF、3DGS 等几乎所有优化推导的统一框架。
