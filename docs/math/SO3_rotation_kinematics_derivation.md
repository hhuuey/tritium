# SO(3)运动学：为什么 Ṙ = RΩ∧ 中的 Ω 是物理角速度 ω？

## 核心问题

从旋转矩阵约束：

\[ R\^TR=I \]

只能推出：

\[ `\dot `{=tex}R = R`\Omega`{=tex}\^`\wedge`{=tex} \]

其中：

-   (`\Omega`{=tex}\^`\wedge`{=tex}) 是反对称矩阵；
-   (`\Omega`{=tex}) 是李代数空间中的切向量。

问题：

> 为什么这个数学上的切向量 Ω 就是刚体运动中的物理角速度 ω？

答案：

需要结合刚体运动学。

------------------------------------------------------------------------

# 1. 旋转矩阵描述刚体姿态

设：

\[ R(t)`\in `{=tex}SO(3) \]

表示从物体坐标系（Body frame）到世界坐标系（Global frame）的旋转。

刚体上的固定点：

\[ p_I \]

在世界坐标：

\[ p_G(t)=R(t)p_I \]

因为点固定在刚体坐标系：

\[ p_I=constant \]

------------------------------------------------------------------------

# 2. 对时间求导

对：

\[ p_G(t)=R(t)p_I \]

求导：

\[ `\dot `{=tex}p_G=`\dot `{=tex}R p_I \]

这表示：

旋转矩阵的变化率决定了刚体点在世界坐标中的速度。

------------------------------------------------------------------------

# 3. 刚体旋转运动学

刚体绕角速度旋转时：

\[ `\dot `{=tex}p_G=`\omega`{=tex}\_G`\times `{=tex}p_G \]

其中：

-   (`\omega`{=tex}\_G)：世界坐标系表示的角速度。

写成反对称矩阵：

\[ `\dot `{=tex}p_G=`\omega`{=tex}\_G\^`\wedge `{=tex}p_G \]

其中：

\[ `\omega`{=tex}\^`\wedge `{=tex}p=`\omega`{=tex}`\times `{=tex}p \]

------------------------------------------------------------------------

# 4. 两个速度表达式比较

由旋转矩阵：

\[ `\dot `{=tex}p_G=`\dot `{=tex}R p_I \]

由刚体运动：

\[ `\dot `{=tex}p_G=`\omega`{=tex}\_G\^`\wedge `{=tex}p_G \]

\[ p_G=Rp_I \]

所以：

\[ `\dot `{=tex}R p_I = `\omega`{=tex}\_G\^`\wedge `{=tex}R p_I \]

对于任意 (p_I)：

\[ `\boxed{
\dot R=\omega_G^\wedge R
}`{=tex} \]

这说明：

如果角速度在世界坐标系表示：

\[ `\dot `{=tex}R=`\omega`{=tex}\_G\^`\wedge `{=tex}R \]

------------------------------------------------------------------------

\[ `\boxed{
